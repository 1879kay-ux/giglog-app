# GigSynq Permissions Matrix

## Current Roles

### Admin
Can manage events, members, documents, availability, finance/admin areas, and app settings.

### Core Band Member
Can view relevant events, update own availability, and access permitted documents.

### Dep
Can view assigned events and update own availability.

### Crew
Can view assigned events and update own availability.

---

## Current Visibility Rules

### Admin
Can view all events.

### Core Band
Can view all events.

### Dep / Crew
Can view assigned events only, unless specifically allowed to view all events.
